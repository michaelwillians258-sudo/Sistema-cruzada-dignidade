# Sistema-cruzada-dignidade

Projeto de extensão universitária desenvolvido para a ONG Cruzada pela Dignidade.

## 📌 Sobre o Projeto
Plataforma web para gestão de cadastro de voluntários, doações e divulgação dos projetos sociais da instituição.

## 🚀 Tecnologias Utilizadas
* HTML5 / CSS3
* JavaScript
* C
